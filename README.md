# Poké Guide V1
Currently only Gen 1 support but the resource works as follows:
1) Select your game version (Red, Blue, Yellow)
2) Choose up to 6 pokémon and create your party
3) Get instant instructions on where and how to get your pokémon chronologically

<a href="https://liltwix2fly.github.io/pokeguide/">Open this link and enjoy!</a>
